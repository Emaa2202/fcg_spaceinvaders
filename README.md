# Esecuzione
Dentro la cartella fcg_spaceinvaders:
- ./build/bin/SpaceInvaders
- Fino a tappa 10 compresa: ./FCG_Stages/Stage_[numeroTappa]/build/bin/main
- Tappe restanti: ./FCG_Stages/Stage_[numeroTappa]/build/bin/SpaceInvaders

# Comandi in-game
- Movimento: A-D
- Sparo: Spazio
- Scudo: LShift
- Colpo bonus: W (si guadagna distruggendo la navicella che passa in alto ogni tanto, compare un alert vicino al punteggio quando disponibile)
- Schermata di pausa: esc

## Variazioni comandi
- Da tppa 2-10 compresa: movimento con freccia destra e sinistra
- Tappa 12: lo scudo si attiva con la freccia in alto
